    A.

    ```
    int a = 10; 
    int b = 20; 
    a = a + b; // a now holds the sum of original a and b 
    b = a - b; // b now holds the original value of a
    a = a - b; // a now holds the original value of b 
    ```

    ```
    a = a ^ b; // a now holds the XOR of original a and b 
    b = a ^ b; // b now holds the original value of a 
    a = a ^ b; // a now holds the original value of b
    ```
